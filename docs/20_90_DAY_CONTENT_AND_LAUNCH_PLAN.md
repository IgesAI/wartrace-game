# 20 — 90-Day Editorial and Organic Growth Launch Plan
**Version:** 1.0 | **Planning horizon:** T-45 to T+45 from an uncommitted launch date. No posting/deploying without explicit owner authorization.

## Critical distinction
Marketing calendars and goals are **experiment plans**, not promises of virality. Content may be prepared immediately, but no public account creation, creator DM, publishing, ad purchase or deployment is authorized by this document.

## Distribution thesis
Every user journey should be: **intriguing question → player submits response → physically satisfying rare-answer movement → spoiler-free visual result → friend tries same challenge**. Build the sharing path before pumping traffic. Optimize qualified referral starts and next-day returns, not raw impression counts.

## Phase A: T-45 to T-31 — Establish identity & prove the hook
Deliverables: original final-ish logo, one genuinely beautiful scene, 10 7-second silent microclips, gameplay copy style, proof of useful archival sources, content correction policy. Run hallway tests with ≥12 different history familiarity levels (target sample, not a completed claim). Record confusion and first-session time-to-answer.

**Content experiments:**
- 6-second 'you think you know WWII' clip with in-game rare answer payoff; no fabricated gameplay.
- Side-by-side common/obscure answer distance result (actual verified test data).
- One artifact close-up + fact, tied to museum source.
- 'Can you name one more?' comment prompt, with clean source follow-up.

## Phase B: T-30 to T-15 — Build waitlist and creator feedback
Prepare a transparent invite-only build with no public leaderboard; recruit 10–20 small creators **only after owner approval**. Capture screen recordings of real product, with permissions. Public-facing content should disclose beta if live. Inspect sources for every shared trivia claim.

**Creative deliverables:** 3 horizontal teaser clips, 8 vertical clips (9:16), 2 square share cards, 1 landing-page GIF-like loop, 5 curated research highlights, 1 editorial transparency post.

## Phase C: T-14 to T-1 — Seven-day content buffer, release rehearsal
Freeze 14+ daily operation bundles. Verify release times and source integrity; simulate 100–500 concurrent game starts if infrastructure supports it. Prepare support FAQ, actual privacy policy, attribution screen and answer appeal system. Create an instrumented share-link funnel. Set public launch controls behind a feature flag.

## Phase D: T0 to T+14 — Controlled public launch
Initial distribution: owned social accounts, small voluntary creator cohort, relevant history/gaming subcommunities where promotion is welcome, optional Discord Activity or challenge plugin **only if already technically ready**. Avoid spam and paid traffic until conversion math is known.

**Daily social rhythm:** 1 playable daily hook at release or morning, 1 optional afternoon creator clip, 1 evening source/explainer after spoiler window. Not three generic engagement posts.

**Observe and decide:** complete rate, share→start, start→complete from referral, actual correction volume, rendering performance, D1 return. If the product is brittle, pause marketing rather than buy reach.

## Phase E: T+15 to T+45 — Retention and editorial expansion
Run controlled tests (not all at once) on: prompt hook, rare-answer reveal, share card, replay duration, historical fact after answer, topic mix, notification opt-in (if added). Build a second environment only if player return/sharing data validates the first one.

## Channel execution guide
**X:** one concise hook (<280 chars) + direct game link; quote-tweet a factual archive record only with correct attribution; avoid misleading quote screenshots. Use plain text + 9:16 clip or 1:1 card; test copy separately.

**TikTok/Reels/Shorts:** vertical 1080×1920, visual hook in the first 0.5–1.5s, full game visual in 1–2s, reveal at 4–7s, invitation as final 2s. Add readable captions; ensure no combat footage masquerades as historical documentary.

**Reddit/communities:** read each community's self-promotion rules, post only where welcome, emphasize genuinely useful history discussion, answer questions directly, disclose product involvement.

**Discord:** weekly invite challenges and a spoiler-safe results channel; no unsolicited DMs or mass invites. Let users opt into recurring events.

**Search/editorial:** publish source-backed explainers for thematic packs, not mass-generated thin SEO pages. A robust evidence page is a better link target than an endless keyword blog.

## Creator collaboration brief
Message is a value proposition, not a press release: 'Try the same seven-question historical expedition your viewers get, then see whose obscure answers advance farther.' Supply 10-minute demo instructions, permitted recording mode, spoiler windows, disclosure language for gifts/sponsorships, affiliate policy if applicable, and no promise of audience size. Identify small history, aviation, tech and gaming creators; ask before outreach.

**Sample-size note:** do not declare a winner at trivial traffic. Log cohorts, time windows, allocation and uncertainty. Use a practical sequential plan and owner review before rollout.

## Growth diagnostics and stop rules
- **Good views, bad starts:** marketing promises wrong product; show real gameplay sooner.
- **Good starts, bad completions:** questions too niche, UX/timer or keyboard defects.
- **Good completions, low shares:** share card unremarkable or challenge is unintuitive.
- **Good shares, low referral starts:** landing page preview/spoilers, slow load, link unfurl bug.
- **Strong D1, weak D7:** content mix repetitive; no weekly payoff.
- **High correctness disputes:** STOP broad promotions until editorial process repaired.
